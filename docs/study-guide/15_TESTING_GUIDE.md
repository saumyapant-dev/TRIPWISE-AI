## 2. API Endpoint Verification (curl Commands)

You can run these curl commands in your terminal to verify backend REST endpoints independently of the frontend:

### 1. Backend Health Check
```bash
curl -X GET http://localhost:5001/api/health
```
**Expected Response:**
```json
{
  "status": "ok",
  "service": "TripWise AI Backend",
  "uptime": 12.45,
  "timestamp": "2026-09-08T..."
}
```

---

### 2. City Geocoding Search
```bash
curl -X GET "http://localhost:5001/api/places/search-cities?q=Athens&country=Greece"
```
**Expected Response:**
```json
{
  "success": true,
  "source": "local",
  "data": [
    {
      "id": "athens_gr",
      "city": "Athens",
      "country": "Greece",
      "coordinates": { "lat": 37.9838, "lon": 23.7275 }
    }
  ]
}
```

### 5. Generate Trip & Persist to SQLite
```bash
curl -X POST http://localhost:5001/api/trips/generate \
  -H "Content-Type: application/json" \
  -d '{
    "city": "London",
    "destination": "Athens, Greece",
    "country": "Greece",

    "duration": 5,

  }'
```
**Expected Response:** `HTTP 201 Created` with full joined trip record containing `id`, `days`, `activities`, and `budgetBreakdown`.

## 3. Fallback & Offline Engine Verification

To demonstrate that TripWise AI is immune to API quota exhaustion or network downtime:

1. **Simulate Missing Gemini API Key:**
   - In `server/.env`, temporarily comment out the key: `# GEMINI_API_KEY=...`
   - Restart backend: `npm run server:dev`
2. **Generate a Trip for a Curated Hub:**
   - Go to `/generate-trip`, set destination to *"Seoul"*, duration `5`, budget `2000`.
   - Click "Generate Trip".
   - **Verification:** The trip generates in under 1 second. Inspect Day 1: it renders *"Gyeongbokgung Palace Royal Guard Ceremony"* with 100% authentic timings and costs from `CURATED_DESTINATION_ITINERARIES`.
3. **Generate a Trip for an Uncurated City:**
   - Set destination to *"Chandigarh, India"*, duration `3`, budget `800`.
   - Click "Generate Trip".
   - **Verification:** Procedural engine synthesizes unique, non-repeating daily themes with proportional budget allocations.
4. **Restore Key:** Uncomment `GEMINI_API_KEY` in `server/.env`.

## 4. Security & Edge-Case Verification

| Test Scenario | Input Data | Expected Defense |
| :--- | :--- | :--- |
| **SQL Injection Attempt** | Destination: `' OR 1=1; DROP TABLE trips; --` | Treated strictly as a literal string. Prepared statement safely searches for that literal city name without executing SQL commands. |
| **XSS Script Injection** | City: `<script>alert('xss')</script>` | React automatically escapes JSX string literals. Rendered safely as harmless text on screen. |
| **Password Timing Attack** | Submitting password with correct first 10 characters vs wrong first character | `crypto.timingSafeEqual()` processes both in identical execution time. |
| **Duplicate Account Creation**| Re-registering `traveler@tripwise.ai` | Server responds with `HTTP 409 Conflict` ("Account with this email already exists"). |
| **Tampered JWT Token** | Modifying any payload character in the JWT token string | Server rejects with `HTTP 401 Unauthorized` ("Invalid authorization token") because HMAC signature verification fails. |
